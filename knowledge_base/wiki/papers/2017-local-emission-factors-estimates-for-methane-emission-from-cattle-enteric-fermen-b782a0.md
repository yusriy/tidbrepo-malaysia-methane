## Abstract

Understanding the magnitude of consequences of climate change caused by greenhouse gases
(GHG) emissions largely relies on GHG inventory stocktaking and emission estimates that
aggregate activity data and emission factors (EF). For that matter, a specific EF to calculate
methane (CH 4) emission from mature beef cattle enteric fermentation has been devised using
IPCC Tier -2 methodol ogy for breeding cows and breeding bulls based on local production
parameters, which in this case, from local beef breed of Brakmas cattle. EF generated for
breeding cows and breeding bulls were 51.6 and 65.7 kg CH 4/animal/year, respectively. The
values ar e higher than the default IPCC value of 47 kg CH 4/animal/year for similar region.
Average value for the generated EF, which was 58.65 kg CH 4/animal/year, with an uncertainty
range of ±30% was used in the calculation of emission using IPCC Tier -1 methodology. The use
of this value resulted in 24.8% higher estimates than when using the default IPCC EF. This EF
value is suggested for use in emission estimates for the national GHG inventory reporting.
